# Varela Barbearia

Site de apresentação e agendamento por WhatsApp para uma barbearia de Fraiburgo (SC).
Feito com HTML, CSS e JavaScript puro.

## Funcionalidades
- Apresentação, serviços e preços
- Galeria de trabalhos
- Formulário que monta a mensagem de agendamento e abre o WhatsApp
- Layout responsivo (celular e computador)

## Como editar
- Textos e preços: `index.html`
- Cores: variáveis no início do `style.css`
- Número do WhatsApp: constante `NUMERO` no `script.js`
- Fotos: pasta `images/`
